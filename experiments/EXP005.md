# EXP005 QUICKSUBMIT: exact evidence baseline

Status: **READY for an AWS speed benchmark; NOT RECOMMENDED FOR LEADERBOARD**.
The frozen held out EVALUATION macro entity level F0.5 is **0.381580**, below
the requested 0.70 recommendation floor. This path does not replace EXP003.
No Amazon TEST was run locally.

## Design

S1 is streamed in source order. For each country string, read the bounded exact
normalized name and address postings from S2 and S3 SQLite indexes. Every
retrieved record is checked against four deterministic policies. A posting with
more than 200 records is skipped in full; no broad token retrieval or arbitrary
prefix of a common posting is used. The inference path does not load labels,
country lists, feature matrices, or an HGB model. Candidate output contains
exactly the retrieved rows whose evidence was evaluated; predictions are a
subset. Empty lists are emitted as empty TSV fields.

The policies are exact name plus exact address, exact name with address token
Jaccard at least 0.5, exact address with name token Jaccard at least 0.5, and
the union of the latter two. All allow exact both. Normalization is from the
existing `normalize.py`; no external data or country specific rule is used.

The source indexes are read only at inference time. Existing EXP002 schema 2
indexes can be reused when they match the supplied source files. The compact
EXP005 index builder is a fallback, writing one SQLite database per target
source. The index stores raw target fields, exact normalized name/address
postings, source fingerprints, and completion metadata. Building TEST indexes
belongs on AWS; it was not performed locally.

## Runtime and output check

Building the two TRAIN indexes from 10,320,219 S2/S3 rows took 587.7 and
617.6 seconds, respectively, and used 3.4 GiB of disk. The 20k development
pass took 68.86 seconds, including S1 and ground truth scans. A separate
10k TRAIN S1 inference smoke, using the frozen policy and prebuilt indexes,
took **23.41 seconds** (about 427 S1/s), emitted 97,630 evaluated candidates
and 6,522 predictions, and passed `validate-output` on all 10,000 rows.
This is a TRAIN runtime measurement; AWS TEST speed remains unmeasured.

Inference retains only one S1 and at most 400 posting IDs and target records
at once, plus SQLite's page caches. A disk backed
`seen.sqlite` uniqueness ledger and streaming TSV writers keep memory bounded
as S1 count grows. Index construction batches 5,000 target rows. The TEST
index build will require disk similar to the TRAIN build; index preparation is
separate from the quoted inference time.

## Reproduce and AWS commands

Local TRAIN reproduction (source path may differ):

```bash
python scripts/run_exp005_quick.py build-index --data-dir data/raw/train --split train --index-dir data/processed/exp005_quick/train_index
python scripts/run_exp005_quick.py develop --train-dir data/raw/train --index-dir data/processed/exp005_quick/train_index --output-dir results/exp005_quick/reproduction
```

On AWS, build TEST target indexes once, unless matching complete EXP002
schema 2 indexes are already present at the supplied index directory:

```bash
python scripts/run_exp005_quick.py build-index --data-dir data/raw/test --split test --index-dir data/processed/exp005_quick/test_index
```

Exact 10k AWS smoke command:

```bash
python scripts/run_exp005_quick.py infer-test --test-dir data/raw/test --index-dir data/processed/exp005_quick/test_index --policy-file results/exp005_quick/frozen_policy.json --output-dir output/exp005_smoke_10k --smoke-limit 10000
```

Exact full TEST command (only after deciding to benchmark or submit):

```bash
python scripts/run_exp005_quick.py infer-test --test-dir data/raw/test --index-dir data/processed/exp005_quick/test_index --policy-file results/exp005_quick/frozen_policy.json --output-dir output/exp005_full --allow-full-test
```

Check each output with `validate-output --source1 data/raw/test/test_source1.tsv
--output-dir <output-dir>` and include `--smoke-limit 10000` for the smoke.
Use fresh output directories; completed runs are never overwritten. The final
submission file is `matching_results.tsv`.
