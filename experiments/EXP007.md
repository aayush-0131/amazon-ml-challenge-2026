## Controls and execution

EXP007 keeps the compact18 pass-eligible candidate pool, original 20k subset,
5,999 FIT / 2,001 TUNE / 12,000 EVALUATION partition, EXP006 deterministic 50k
EXTRA_FIT sample, old 51-feature prefix, negative sampler, HGB model factory,
and competition macro-F0.5 evaluator. No candidate injection or expansion is
permitted. The old EXP003/EXP006 code and artifacts remain untouched. New
outputs live only in `results/exp007_*` paths; the pre-existing
`results/exp006_50k_sample` is read-only. EVALUATION pair generation requires
the frozen TUNE bundle. The separate blocker-oracle diagnostic reads the exact
complete EXP003 eligible EVALUATION pool after checksum validation; it is not
used for model fitting or policy selection.

The blocker oracle predicts truth intersect eligible IDs for every S1. Its
macro score is computed by `evaluate_predictions`, including singleton
semantics, and is reported by country, source, source x country and
multiplicity. A score below 0.985 flags blocking as material; a score at least
0.990 with a large model gap points to the matcher. This is an offline ceiling,
not a submission prediction. The complete TRAIN target audit gates optional
exclusivity: any S2 or S3 target with multiple S1 owners disables it. When
enabled, the highest score wins and an S1-ID lexical tie break is fixed.

The secondary representation adds 32 features to the old 51. It uses pinned
AnyAscii 0.3.3 for transliteration, with separate full/core name forms, URL and
legal-suffix cleanup, digit-letter splitting, normalized numeric tokens,
postal-like tokens, name/address similarities and numeric conflicts. The
AnyAscii Python package is ISC licensed. The original conservative normalizer
and blocker are unchanged. The trained model weights are project-trained MIT;
scikit-learn is BSD-3-Clause. No external identity data are used.

The primary matcher is the EXP006 HGB configuration. The decision experiments
use two entity-isolated out-of-fold HGB fits on original FIT entities, with the
same sampled negative protocol, to fit a singleton guardian and logistic
relative-score policies. The main HGB uses original FIT plus 50k EXTRA_FIT.
The TUNE-only ablations compare global versus S2/S3 threshold grids, guardian,
audited exclusivity, relative score evidence, bounded top-3 by top-3 S2/S3
evidence, and optional numeric penalties. Each source grid covers 0.50-0.84
by 0.01 and 0.850-1.000 by 0.001, plus a reject-all sentinel. Macro-F0.5
ties choose the more conservative threshold combination. Guardian abstention
cutoffs use 0.00-0.90 by 0.02. Calibration is not attempted because a separate
calibration split is not reserved; the ablation CSV records this omission.
The best TUNE policy is frozen once, then EVALUATION runs once.

shard. Use four separate workers only after confirming memory and disk headroom.

## Outputs and gate

The oracle directory has `blocker_oracle_tune.json` and
`blocker_oracle_evaluation.json`; ownership has `target_ownership_audit.json`.
Each pair partition has `.f32`, `.tsv` and checksum manifest files. FIT has
`models.joblib` and `fit_manifest.json`. TUNE has `feature_names.json`,
`feature_count.json`, `tune_ablations.csv`, `selected_policy.json`,
`frozen.joblib`, and `freeze.json`. EVALUATION has `evaluation.csv`,
`evaluation_slices.csv`, `guardian_metrics.json`, `duplicate_claims_audit.json`,
`numeric_conflict_audit.json`, `cross_source_audit.json`, `summary.json`, and
`artifact_manifest.json`.

`summary.json` compares exact EXP003 0.905874 and EXP006 0.9136711411208787
baselines, precision/recall/FN/singleton deltas, and the blocker oracle gap.
Gate: below 0.920 REJECT; 0.920-0.929999 WEAK; 0.930-0.939999 MEANINGFUL;
0.940-0.949999 STRONG; at least 0.950 MAJOR RESULT. No policy is promoted on
recall alone. There is no automatic TEST command, submission, or merge.

The pair cache and SQLite shards are large. Four workers duplicate S1/ground
truth scans and read the same country-scoped TRAIN indexes. HGB fitting holds
the full float32 matrix and labels and needs headroom beyond the matrix size.
Source thresholds search a fine joint grid over 2,001 TUNE entities. Monitor
RSS and disk before concurrent workers. Keep EXP007 training away from EXP006
TEST inference if the processes share the same host resources; never point
EXP007 at EXP006 TEST indexes, checkpoints, or output paths.
